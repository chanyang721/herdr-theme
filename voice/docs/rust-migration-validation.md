# Native voice migration validation

The reference implementation is the public repository at `8c5b71d2f1074bb5d1d831fa395617bf4ae2abc8`. The native entry points live in `rust/src/voice`; installed plugin manifests, Claude hooks, the Codex LaunchAgent and sidebar integration invoke `herdr-theme` directly. The executable uses PortAudio and a pinned sherpa-onnx C API, with the existing ONNX model names and per-device voice-state schema. No installed voice command invokes Python, pip, uv or a virtual environment.

| Previous component | Native command or module | Evidence prepared |
|---|---|---|
| `focusq`, plugin installer and Codex installer | `focusq`, `voice_install`, `install_codex_focus` | Native hook relocation and settings-preservation tests; isolated LaunchAgent and plugin-copy tests; macOS atomic-exchange test |
| Voice settings and submit policy | `voice_submit_hook`; public `settings.rs` and `policy.rs` APIs | Frozen original input/output cases; real submit engine tests for refusal stderr, exit 2, local evidence files and late verdict retry |
| Focus queue and per-pane dictation | `focus_queue`; `queue.rs` | Original screen/dim-text parsing, F8 retry, source/native projection and settings-scene fixtures |
| Codex microphone focus guard | `codex_focus`; `queue.rs` | Break-before-make, manual mute ownership, failed mute and identity tests |
| Confirmed voice-loss recovery | `voice_recovery`; `recovery.rs` | Original failure-marker, eligibility, device-selection and device-signature fixtures |
| Voice enrollment, verdicts and adaptation | `voicegate`; `gate.rs`, `native.rs` | Original cluster and threshold fixtures; owned C handles and pinned ABI |
| Model, VAD and complete gate experiments | `voice_eval_models`, `voice_eval_vad`, `voice_eval_gate_chain` | Native Parquet/audio decoding, SOS filtering, noise and FFT/reverb implementations; frozen NumPy random streams and SciPy coefficients |
| Other-device and local-submission diagnostics | `voice_check_other_device`, `voice_replay_policy`, `voice_check_settings` | Native implementations preserving source datasets, local input schemas and experiment scenes |

Executing the original library-only `app_backend`, `voice_policy` or `voice_settings` aliases remains a no-op with exit zero and no stdout. Their callable functionality is retained by the public Rust modules and the explicit test probe; a JSON-dumping settings CLI is not substituted for the original no-op behavior.

The frozen behavior corpus contains 284 synthetic cases generated by executing the original Python functions. Identifiers were made synthetic before recomputing reference outputs. The random corpus contains 1,000 normal samples, 1,000 bounded integers and one permutation for each of the original fixed seeds 3, 7 and 11. A separate DSP corpus retains 7,168 original output samples for level normalization, filtered noise, headset filtering and room reverberation, checked at an absolute float32 tolerance of `1e-7`. NumPy-derived tables retain their third-party license. These fixtures do not include user transcripts, recordings, personal paths or internal task records.

Run `CARGO_BUILD_JOBS=1 cargo test --manifest-path rust/Cargo.toml voice:: -- --test-threads=1`. Tests containing native OS operations must run on macOS too. `voice/tests/native-install.test.mjs` exercises the installed executable with an isolated home and fake Herdr tool; it never starts a LaunchAgent or downloads models.

The following evidence is still required before claiming complete behavioral equivalence:

- Run the macOS installer integration, repeated install, actual directory exchange and native process entry points on both supported Mac architectures.
- Compare original and native embedding vectors and VAD segment boundaries on the same fixed audio/model files. The native C library is pinned to sherpa-onnx 2.0.1; parity with whichever Python wheel an existing installation used is not established by matching model names.
- Compare numerical model/VAD/gate-chain experiment outputs on the same public dataset. [offline-evaluation-validation.md](offline-evaluation-validation.md) describes a full-loop synthetic Parquet comparison derived from pinned public speech, including the measured far-channel convolution drift and required post-fix evidence.
- Observe actual default-device changes, disconnected/stalled microphone recovery, CoreGraphics physical-key timing, app/TUI focus races and in-flight dictation on a Mac. Pure fixtures and Windows compilation cannot establish these results.
- Obtain independent review and required CI results for the complete migration. Code compilation or fixture passes alone are not live voice acceptance.

Native executable names and install manifests necessarily replace interpreter/script argv. Installer dependency messages and CLI usage examples describe the native setup. Diagnostic formatting is currently concise native output rather than Python exception tracebacks. The numerical and live-platform checks above remain explicit migration acceptance work; no live installation or session restart is implied by these source changes.
