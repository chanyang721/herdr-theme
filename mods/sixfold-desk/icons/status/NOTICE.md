# Session state images

These images were packaged from original rendered pixel-effect frames using an
MIT-licensed renderer. The retained stationary PNGs and lossless animated WebP
files support dark/light palettes and 12/16 pixel slots. Frame timing and file
hashes are listed in `manifest.json`. No external service or renderer runs in
the theme.
