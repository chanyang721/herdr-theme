# System Metrics

Native macOS CPU and memory strip for Herdr. Read RECIPE.md, install the native Herdr Theme helper, then copy `mods/system-metrics` to your app’s mods folder and run `herdr-app check ~/.config/herdr-app/mods/system-metrics`. The helper runs `system_metrics`; the pinned full monitor additionally supports Windows and remote reads. This legacy local-only strip has no network or authentication. Apache-2.0.
